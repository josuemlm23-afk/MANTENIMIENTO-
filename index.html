🚀 Cómo crear tu Firebase gratis

  1. Ve a console.firebase.google.com
  2. Clic en "Crear un proyecto" → ponle un nombre → continuar
  3. Una vez creado, en el menú lateral: Compilación → Firestore Database
  4. Clic "Crear base de datos" → elegir modo de prueba → siguiente
  5. En el menú lateral: Configuración del proyecto ⚙️ → pestaña "General"
  6. En "Tus apps", clic en el ícono web </>, registra la app
  7. Copia los valores de apiKey, projectId y appId
  8. Regresa al inicio de esta app y pégalos en la pantalla de configuración

🔒 Reglas de seguridad (importante)

  1. En Firebase Console → Firestore → Reglas
  2. Pega este código y publica:
    rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { match /registros/{id} { allow read, write: if true; } } }

📤 Cómo compartir con tus técnicos

  1. Sube este archivo HTML a Google Drive
  2. Comparte el link con tus técnicos
  3. Cada técnico abre el link, pone las credenciales de Firebase y ya puede registrar
  4. Tú ves todos los registros en tiempo real desde la pestaña "Registros"
